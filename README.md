# Seth Martin — Student Portfolio

A responsive personal portfolio built with Bootstrap 5 and custom CSS. The page introduces Seth Martin, highlights current learning interests, and includes a locally stored SVG illustration.

## Preview locally

Open `index.html` in a browser. Bootstrap and the display fonts are loaded from CDNs, so an internet connection is needed for those external resources. The illustration is stored in `assets/`.

## Host with AWS Amplify

1. Push this repository to GitHub or AWS CodeCommit.
2. In the AWS Amplify console, choose **Create new app** and connect the repository and branch.
3. Keep the default build settings for a static site with no build step.
4. Deploy the app and open the generated Amplify URL. Future pushes to the connected branch will trigger a redeployment.

No commit or cloud deployment is performed as part of this repository change.
